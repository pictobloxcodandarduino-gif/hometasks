# Home Tasks — Streamlit + Supabase

برنامه فارسی مدیریت نوبت کارهای خانه با یک حساب مدیر، بدون نیاز به ایمیل.

## امکانات
- یک حساب مدیر با نام کاربری و رمز عبور
- تغییر رمز از داخل نوار کناری
- شش کار: جارو، ظرف‌ها، آشغال، سفره، خرید، لباس‌ها
- سه نفر: هانی، احمرضا، ارمیا
- با انجام کار، نفر اول به انتهای صف همان کار می‌رود
- ذخیره دائمی و مشترک در Supabase
- بازنشانی نوبت‌ها

## ۱) ساخت دیتابیس Supabase
1. به https://supabase.com بروید و یک پروژه بسازید.
2. از بخش SQL Editor، فایل `schema.sql` را کامل اجرا کنید.
3. از Project Settings → API، مقدار Project URL و کلید `service_role` را بردارید.
   **کلید service_role محرمانه است؛ آن را در GitHub یا کد عمومی قرار ندهید.**

## ۲) تنظیم Secrets برای اجرای محلی
پوشه `.streamlit` را دارید. فایل زیر را از روی نمونه بسازید:
`.streamlit/secrets.toml`

مقادیر نمونه را با اطلاعات واقعی جایگزین کنید:
```toml
SUPABASE_URL = "https://YOUR-PROJECT.supabase.co"
SUPABASE_SERVICE_ROLE_KEY = "YOUR-SERVICE-ROLE-KEY"
INITIAL_ADMIN_USERNAME = "admin"
INITIAL_ADMIN_PASSWORD = "Choose-A-Strong-Initial-Password"
```
رمز اولیه را قوی و غیرقابل حدس انتخاب کنید. حساب مدیر در اولین اجرای برنامه ساخته می‌شود. پس از اولین ورود می‌توانید رمز را از داخل برنامه تغییر دهید. مقادیر اولیه فقط برای ایجاد حساب در اولین اجرا هستند.

## ۳) اجرای محلی
Python 3.10 یا جدیدتر پیشنهاد می‌شود:
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## ۴) انتشار برای گوشی و کامپیوتر
1. فایل‌های پروژه را در یک مخزن خصوصی یا عمومی GitHub قرار دهید. فایل secrets.toml را هرگز commit نکنید.
2. در https://share.streamlit.io/ وارد شوید و مخزن را انتخاب کنید.
3. در Advanced settings → Secrets، همان چهار مقدار TOML بالا را وارد کنید.
4. Deploy را بزنید.
5. لینک منتشرشده را روی گوشی و کامپیوتر باز کنید. در گوشی از منوی مرورگر Add to Home Screen را انتخاب کنید.

## امنیت
- برنامه فقط یک حساب مدیر دارد؛ هانی، احمرضا و ارمیا حساب ورود ندارند.
- رمز در دیتابیس به صورت PBKDF2-HMAC-SHA256 با salt تصادفی ذخیره می‌شود.
- دسترسی دیتابیس فقط از سمت سرور برنامه با service_role انجام می‌شود.
- جدول‌ها RLS دارند و برای anon/authenticated policy عمومی تعریف نشده است.
- تابع‌های تغییر نوبت فقط برای service_role قابل اجرا هستند.
- هرکسی که رمز مدیر را بداند می‌تواند وارد شود؛ رمز را با افراد غیرمجاز به اشتراک نگذارید.

## همگام‌سازی
برنامه هر ۵ ثانیه وضعیت دیتابیس را دوباره می‌خواند؛ بنابراین تغییرات دستگاه دیگر معمولاً حداکثر طی چند ثانیه در این دستگاه هم دیده می‌شود. پس از فشردن دکمه انجام شد، تغییر بلافاصله در دیتابیس ذخیره می‌شود. دکمه تازه‌سازی دستی نیز وجود دارد.

## نکته
همگام‌سازی خودکار با polling پنج‌ثانیه‌ای انجام می‌شود؛ این روش ساده و مناسب نسخه اول است. در صورت نیاز می‌توان بعداً Supabase Realtime را برای همگام‌سازی رویدادمحور جایگزین کرد.

## تغییر جدید: انتخاب هر شخص و شمارنده مستقل

اگر نسخه قبلی دیتابیس را قبلاً راه‌اندازی کرده‌اید، فایل `update_for_individual_checkmarks.sql` را در Supabase از مسیر SQL Editor اجرا کنید. این کار ستون شمارنده‌ها و تابع جدید ثبت انجام کار را اضافه می‌کند؛ داده‌های قبلی نوبت‌ها حفظ می‌شوند و شمارنده‌ها از صفر شروع می‌شوند.

سپس فایل `app.py` جدید را در مخزن GitHub جایگزین نسخه قبلی کنید. در هر کارت کار، می‌توانید تیک هر یک از سه نفر را جداگانه بزنید. تعداد دفعات انجام همان کار برای همان شخص کنار نامش نمایش داده می‌شود. ثبت هر تیک، شمارنده را یک واحد زیاد می‌کند و نوبت آن شخص را در صف همان کار به انتها می‌برد. شمارنده‌های هر کار مستقل‌اند.
